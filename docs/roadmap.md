## 進め方の原則（アジャイル）

- **“器”を先に完成させ、ツールは1つずつ継続的に追加**する。
- 各ツールは独立モジュール（`features/<tool>/`）なので、小さく作って速くリリースできる。
- フェーズは厳密な期限ではなく「達成したら次へ進む」マイルストーンとして扱う。

---

## Phase 0 — 基盤構築（器づくり）🏗️

**ゴール**: ツールを足せる土台が動く状態。トップ＋ツール1個が実際に表示される。

- [ ] Astro + React + Tailwind + TypeScript のプロジェクト初期化
- [ ] Cloudflare アダプタ設定（`@astrojs/cloudflare`）
- [ ] ディレクトリ構成を仕様書どおりに作成
- [ ] 共通レイアウト（Header / Footer / ダークモード）
- [ ] ツールのメタデータ型・レジストリ（`registry/tools.ts`）
- [ ] トップページ（カード一覧＋クライアント検索）
- [ ] ツール個別ページの動的生成（`tools/[slug].astro`）
- [ ] **サンプルツール1個**（例: JSON整形）を feature として実装＝追加パターン確立
- [ ] ロジックの単体テスト1本（Vitest 導入確認）
- [ ] プライバシーポリシー／`ads.txt`（空枠）／`robots.txt`／sitemap の箱

**完了条件**: `npm run dev` でトップとツール1個が動作し、「featureを足せば増える」ことが実証できる。

## Phase 1 — 初期ツールラインナップ（審査準備）📦

**ゴール**: AdSense 審査に出せるだけのコンテンツ量と品質。各ジャンルに定番を揃える。

- [ ] 開発者系: JSON整形 / Base64エンコード・デコード / URLエンコード
- [ ] テキスト系: 文字数カウント / ケース変換 / Markdownプレビュー
- [ ] 日常・計算系: 単位変換 / パスワード生成
- [ ] 画像・メディア系: QRコード生成（クライアント完結の軽いものから）
- [ ] 各ツールに固有のSEOメタ・説明文
- [ ] レスポンシブ・アクセシビリティ最終調整
- [ ] Lighthouse 90+ 確認

**完了条件**: 実用的なツールが8〜10個稼働し、サイトとして成立している。

## Phase 2 — 公開・収益化 💰

**ゴール**: 本番公開し AdSense 収益化を開始、検索流入を取り始める。

- [ ] 独自ドメイン設定・Cloudflare Pages 本番デプロイ
- [ ] `ads.txt` 正式配置＋Cloudflare チャレンジ除外設定
- [ ] AdSense 申請 → 承認
- [ ] 承認後、広告枠（`components/ads/`）を有効化
- [ ] SEO強化: sitemap.xml 自動生成 / 構造化データ / OGP画像
- [ ] Google Search Console / アナリティクス導入

**完了条件**: 広告配信開始、検索エンジンにインデックスされ流入が計測できる。

## Phase 3 — 拡充・グロース 📈

**ゴール**: 利用データを見ながらツールを増やし、価値を高める。

- [ ] サーバー処理が要るツール（画像圧縮・変換など）を Pages Functions で実装
- [ ] 利用数の多いカテゴリのツールを優先拡充
- [ ] 人気ツールのUX改善（履歴・プリセット・共有URL等）
- [ ] パフォーマンス/広告配置のABテスト的な見直し
- [ ] （検討）お気に入り、ダークモード以外のテーマ、多言語対応
